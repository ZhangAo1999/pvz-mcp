# PvZ MCP

通过 MCP 让 AI 游玩《植物大战僵尸》：读取游戏状态，自主决定种植位置和等待时间，再通过工具执行操作。整个过程可以不看画面、不操作鼠标。

当前版本：`0.3.1-preview.1`，支持 Windows x64 上运行的特定 **1.2.0.1073** 构建。

本项目提供工具源码和安装脚本，不包含游戏文件、资源或存档。使用者需要自行准备兼容的游戏，以及支持本地 stdio MCP 的 AI 客户端。

## 功能

- **读取局势**：以 JSON 获取植物、僵尸、子弹、血量、阳光、卡牌冷却、物品和波次等状态。
- **控制节奏**：暂停游戏、按指定时长推进后再次暂停，或持续运行；支持调整倍速。
- **执行操作**：选择模式与关卡、选卡、按正常规则种植、拾取物品。
- **观战提示**：显示决策计时、推进倒计时，以及 AI 的打算和操作说明。
- **管理进度**：读取存档信息，在主菜单修改冒险进度并备份原档。

默认自动拾取阳光，使用原生声音和收集动画，不增加额外阳光。工具本身不包含自动决策策略，如何游玩由连接它的 AI 决定。

## 兼容性

| 游戏构建 | 状态 | 验证范围 |
| --- | --- | --- |
| 1.2.0.1073，下方所列 SHA-256 | 已适配 | 启动、菜单、冒险 1-4 的状态读取、暂停推进、种植、阳光拾取与返回菜单等基础操作已实机验证 |
| 1.0.0.1051，已检查构建 | 不支持 | 当前适配无法直接使用，可安装工具但不能启用游戏控制 |
| 其他同版本构建、汉化或修改版 | 未验证 | 版本号相同也不保证兼容 |
| 其他 Steam / GOTY 构建、重制版及移动版 | 未适配 | 暂不支持 |

**目前只有下列 EXE 哈希可以启用游戏控制。**选择其他构建或暂不选择游戏时，仍可安装工具；游戏控制保持禁用，不会强行加载桥接。未验证不等于一定不兼容，但需要另行验证后才能启用。

```text
e1511201ec2ae9a7e30259f04bc2ec7272badb2574a2e9b405d0e916ae5c082c
```

可在 PowerShell 中检查：

```powershell
Get-FileHash -LiteralPath 'D:\Games\PvZ\PlantsVsZombies.exe' -Algorithm SHA256
```

尚未覆盖所有关卡和模式。冒险 1-5 是坚果保龄球，当前没有对应的专用操作；回放、金币编辑、全植物解锁和任意存档编辑也尚未实现。

## 快速开始

### 使用 EXE 安装器

1. 从 [Releases](https://github.com/ZhangAo1999/pvz-mcp/releases) 下载并运行 `PvZ-MCP-版本号-Setup.exe`。
2. 选择工具安装目录，默认 `D:\Programs\PvZ-MCP`。
3. 选择自己的 `PlantsVsZombies.exe`，界面会校验文件并显示兼容性。
4. 点击“安装 / 更新”。安装器自带 Node.js、Python 和 MCP 依赖，无需另行下载。
5. 将安装目录生成的 `mcp-config.json` 合并到 AI 客户端的 MCP 配置中，重新连接服务。配置格式可能需要按客户端要求转换。
6. 配置了受支持游戏后，让 AI 调用 `pvz_status` 检查状态，再调用 `pvz_launch_game` 启动。

未配置受支持游戏时，工具仍可安装，MCP 会返回 `GAME_NOT_CONFIGURED`。重新运行安装器即可选择游戏。选择不支持的文件会停用先前的游戏配置并备份；仅勾选“不选择游戏”则保留已有配置。

安装器不会自动修改 AI 客户端配置，也不会启动或改写所选游戏。

从源码构建的 ZIP 离线包，解压后可使用 `Install.cmd`，或通过命令行安装：

```powershell
.\Install.ps1 -InstallDir 'D:\Programs\PvZ-MCP' -GamePath 'D:\Games\PvZ\PlantsVsZombies.exe' -NonInteractive
```

只安装工具：

```powershell
.\Install.ps1 -InstallDir 'D:\Programs\PvZ-MCP' -InstallToolsOnly -NonInteractive
```

**源码仓库与安装包不同。**从源码运行和构建 EXE 请参阅[开发说明](docs/DEVELOPMENT.md)。

### 启动方式

请从 MCP 启动游戏。如果游戏已通过双击 EXE 打开，先正常退出，再调用 `pvz_launch_game`。

工具在新进程启动时加载内存桥接，**不改写游戏 EXE 或资源文件**；关闭游戏后桥接自然消失。游戏仍会正常保存进度，管理员改档操作也会写入存档。

同一时间建议只运行一份游戏，并由一个客户端控制。AI 客户端需要具备本机 MCP 执行能力。

## 让 AI 开始游玩

连接成功后，可以向 AI 提出这样的要求：

> 通过 PvZ MCP 按当前存档进度开始冒险，不增加阳光。每轮暂停读取 JSON，自主决定种植和下一次等待时长，保持 1 倍速，并用简短观战说明解释操作。

典型流程：

```text
检查状态 → 开始关卡 → 读取暂停快照 → 判断并操作 → 推进一段时间 → 再次判断
```

默认每次推进 2 秒游戏时间，也可以由 AI 按局势选择更长的间隔。种植遵守阳光、冷却与地形规则。选关参数 `level` 只在明确指定关卡时使用；省略时按当前存档进度开始。

工具参数、身份校验、异步推进和领奖处理见[调用说明](docs/USAGE.md)。

## MCP 工具列表

当前提供 **18 个工具**。具体操作受当前场景、模式和解锁状态限制。

| 工具 | 用途 |
| --- | --- |
| `pvz_status` | 只读查询游戏进程、场景和控制状态 |
| `pvz_launch_game` | 启动受支持的游戏并加载桥接，或复用已连接的进程 |
| `pvz_list_modes` | 查询模式目录和支持信息 |
| `pvz_start_game` | 开始冒险或指定模式，支持显式选关 |
| `pvz_return_to_menu` | 返回主菜单，离开当前关卡 |
| `pvz_get_state` | 暂停并读取一致的 JSON 游戏状态 |
| `pvz_pause` | 暂停模拟，保留控制入口 |
| `pvz_advance` | 推进指定时长或更新次数，然后再次暂停 |
| `pvz_resume` | 持续运行，可指定倍速 |
| `pvz_select_seeds` | 按实际解锁情况选择卡组并开始 |
| `pvz_can_place` | 检查卡槽、费用、冷却和格子合法性 |
| `pvz_place_plant` | 正常种植，扣除阳光并触发冷却 |
| `pvz_collect` | 拾取已有阳光、钱币或 1-4 铲子奖励 |
| `pvz_set_presentation` | 设置倍速、观战提示、说明保留时间和默认推进时长 |
| `pvz_set_commentary` | 显示 AI 的简短打算和本次操作说明 |
| `pvz_get_save_info` | 只读查询当前用户存档、进度和校验信息 |
| `pvz_admin_set_progress` | 管理员功能：备份后持久修改冒险进度 |
| `pvz_admin_set_sun` | 管理员功能：直接设置局内阳光 |

普通种植与选卡当前覆盖冒险和植物僵尸的相应原生规则，模仿者暂不支持。模式出现在目录中，不代表已解锁或已完成实机验证。

管理员接口会改变正常游戏状态，应按使用者明确要求调用。返回主菜单会离开当前关卡，未结算的局内进度可能丢失。

## 升级与回退

关闭游戏并断开 MCP，运行新版 EXE 安装器或 ZIP 离线包，选择原安装目录即可升级。用户配置和备份会保留，重新连接 MCP 后使用新版。

需要回退时，在安装目录运行：

```powershell
.\Manage.ps1 -Action Rollback
```

回退只切换工具版本，不恢复游戏存档。当前不提供在线更新检测或自动下载。
